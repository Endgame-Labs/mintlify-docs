Connect Chorus so Endgame can learn from your team's calls. Once connected, Endgame brings in your Chorus call transcripts and uses them in its insights and answers.

## Before you start

- You need to be an Endgame admin.
- The person creating the API key must be a Chorus administrator.
- You'll need a Chorus API key. In Chorus, go to **Settings** > **API Access** and click **Generate API token**.

<Info>
  Endgame can only bring in calls that the person who created the API key can
  access in Chorus. If you're not seeing the calls you expect, the key's
  permissions are the likely cause. Contact us at
  [support@endgame.io](mailto:support@endgame.io) for help.
</Info>

## Connect Chorus

1. In [**Settings** > **Organization** > **Integrations**](https://app.endgame.io/settings/integrations), find Chorus and click **Connect**. You can search for "Chorus", or choose **Available** to show only integrations you haven't connected yet.
2. Enter your Chorus **API key**, then click **Connect**.

    src="/images/chorus-connect-dialog-10-20-26.png"

    className="rounded-lg"
  />
</Frame>

Endgame opens the Chorus page, which shows **Connected** at the top, and starts bringing in your call transcripts.

## Update credentials or disconnect

Use the **Connection** section at the bottom of the Chorus page. See [Manage a connected integration](/integrations/overview#manage-a-connected-integration).

- **Update credentials** opens the same dialog as connecting, with nothing prefilled. Use it when you generate a new API key.
- **Disconnect** stops syncing call transcripts from Chorus.
