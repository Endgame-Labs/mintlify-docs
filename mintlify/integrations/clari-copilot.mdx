Connect Clari Copilot so Endgame can bring in your call transcripts and conversation insights. Once it's connected, Endgame keeps syncing new calls and uses them for analysis and answers.

## Before you start

- You need to be an Endgame admin and a Clari Copilot administrator.
- Your organization needs a Clari Copilot Enterprise plan to use the Clari Copilot API.
- You'll need an **API key** and **API password** from Clari Copilot. See [Find your API key and password](#find-your-api-key-and-password).

<Warning>
  Salesforce must be connected to Clari Copilot. Endgame uses the Salesforce account IDs on Clari Copilot calls to link each transcript to the right account. Without them, Endgame can't match calls to accounts.
</Warning>

## Find your API key and password

In Clari Copilot, go to **Workspace Settings** > **Integrations** > **Clari Copilot API**, or open [Admin Integrations](https://copilot.clari.com/settings#adminIntegrations) directly. Copy the **API Key** and the **API Secret**. Endgame calls the secret your API password.

## Connect Clari Copilot

1. In [**Settings** > **Organization** > **Integrations**](https://app.endgame.io/settings/integrations), find Clari Copilot and click **Connect**.
2. Enter your **API key** and **API password**, then click **Connect**.

<Frame caption="Connecting Clari Copilot needs your API key and API password.">
  <img
    src="/images/clari-copilot-connect-dialog-10-20-26.png"

Endgame opens the Clari Copilot page and starts syncing your call data. There's nothing else to set up.

## Update credentials or disconnect

Use the **Connection** section at the bottom of the Clari Copilot page. See [Manage a connected integration](/integrations/overview#manage-a-connected-integration).

- **Update credentials** opens the same dialog as connecting, with nothing prefilled. Use it after you regenerate your API key in Clari Copilot.
- **Disconnect** stops syncing call transcripts from Clari Copilot. Endgame asks you to confirm first. To reconnect later, you'll need your API key and password again.
