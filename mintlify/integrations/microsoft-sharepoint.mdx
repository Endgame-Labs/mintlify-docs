Connect Microsoft SharePoint so Endgame can use the documents in your SharePoint document libraries in its answers. You choose which libraries to sync, and Endgame keeps them up to date.

## Before you start

- You need to be an Endgame admin and a SharePoint Administrator.
- You'll sign in with your Microsoft account and approve Endgame's access for your organization, so have that account ready.

## Connect Microsoft SharePoint

1. In [**Settings** > **Organization** > **Integrations**](https://app.endgame.io/settings/integrations), find Microsoft SharePoint and click **Connect**. Microsoft's sign-in page opens.
2. Pick the Microsoft account you want to connect.
3. On the permissions screen, check **Consent on behalf of your organization**, then click **Accept**.

Endgame opens the Microsoft SharePoint page so you can choose what to sync.

## Choose document libraries to sync

1. In **Add document library**, search for the SharePoint site that has the library you want.
2. Pick the site. Its document libraries are listed below it.
3. Click **Select** next to each library you want to sync. To pick a different site, click **Change site**.

<Frame caption="Pick a site, then click Select next to each document library you want to sync.">
  <img
    src="/images/sharepoint-add-document-library-10-23-26.png"

Endgame syncs a library as soon as you add it, and then every 15 minutes. If a file is removed from a library you sync, Endgame removes it too.

Your libraries are listed in **Synced document libraries**, with their site, file count, and when they last synced. Click a library to see its files.

To stop syncing a library, click the trash icon next to it, then click **Remove**. This also deletes the documents Endgame synced from that library.

<Note>
  Endgame _only_ syncs the document libraries you add here. It doesn't sync anything else in SharePoint.
</Note>

## Update credentials or disconnect

Use the **Connection** section at the bottom of the Microsoft SharePoint page. See [Manage a connected integration](/integrations/overview#manage-a-connected-integration).

- **Update credentials** takes you to Microsoft's sign-in page, for example to connect with a different account. Your document libraries stay as they are.
- **Disconnect** stops syncing documents from SharePoint. Documents Endgame already synced stay in Endgame. To delete them, remove their libraries before you disconnect.
